Levantar requisitos
	Quais informações existem no contexto do sistema?
	Times, jogadores, campeonatos, jogos.

	Quais ações podem acontecer?
	user-end
		Visualizar informações de um campeonato
		Visualizar informações de um time
		Visualizar informações de um jogador
		Visualizar informações de um jogo

	admin-end
		Cadastro de campeonato
		Alteração de campeonato
		Cadastro de time
		Alteração de time
		Cadastro de jogador
		Alteração de jogador
		Cadastro de jogo
		Alteração de jogo

	Quais consultas, telas, relatórios ou APIs precisarão desses dados?
	Todos esses dados listados funcionam de forma complementar um do outro, inclusive durante consultas.

	O que torna um registro único?
	Um campeonato se torna único através de seu nome, país e ano.
	Um time se torna único através do seu nome, país e estado.
	Um jogador se torna único através do seu nome, país, data de nascimento, time e número da camisa.
	Um jogo se torna único através do seu campeonato, data e times relacionados.



Modelagem conceitual
	Descrever
		Entidades relevantes do domínio.
			Campeonato, time, jogador, jogo.

		Relações entre entidades.
			Campeonato tem n Times
			Time joga n Campeonatos

			Campeonato tem n Jogos
			Jogo pertence a um Campeonato

			Time tem n Jogadores
			Jogador pertence a um Time

			Time joga n Jogos
			Jogo tem 2 Times

	Validar com o requisitos de negócio



Modelo lógico
	Definir para cada entidade
		Atributos: quais propriedades precisam ser registradas.
			Campeonato: nome, país, ano, data de início, data de término
			Time: nome, país, estado, técnico, estádio
			Jogador: nome, país, data de nascimento, time, posição, pé dominante, número
			Jogo: campeonato, data, horário, time mandante, time visitante, estádio

		Identificador: a chave primária que distingue cada ocorrência.
			Campeonato: nome, país, ano
			Time: nome, país, estado
			Jogador: nome, país, data de nascimento, time, número
			Jogo: campeonato, data, horário, time mandante

		Relacionamentos: e Chaves estrangeiras
			Campeonato - Time [Uma terceira tabela que referencia as duas]
			Campeonato - Jogo [Jogo usa o idCampeonato como chave estrangeira]
			Time - Jogador 	  [Jogador usa idTime como chave estrangeira]
			Time - Jogo       [Jogo usa idTime como chave estrangeira] [Terá 2 idsTime, um do time mandante e outro do visitante]



Modelo físico
	Nomes reais de schemas, tabelas e colunas.
		Tabelas e Colunas: 
			championship
				id 									[BIGINT] 		PK
				name 								[VARCHAR(150)] 	NOT NULL
				country_id 							[BIGINT] 		FK, NOT NULL

				UNIQUE(name, country_id)

			championship_season
				id 									[BIGINT] 		PK
				championship_id						[BIGINT]		FK, NOT NULL
				year								[SMALLINT]		NOT NULL
				start_date							[DATE]			NOT NULL
				end_date							[DATE]			NOT NULL
				status								[VARCHAR(20)]	NOT NULL

				UNIQUE(championship_id, year)
				CHECK(end_date >= start_date)

			club
				id 									[BIGINT] 		PK
				name 								[VARCHAR(150)]	NOT NULL
				country_id 							[BIGINT] 		FK, NOT NULL
				state 								[VARCHAR(100)]
				stadium_id 							[BIGINT] 		FK, NOT NULL
				founded_at							[DATE]	

				UNIQUE(name, country_id)

			championship_season_club
				id 									[BIGINT] 		PK
				championship_season_id  			[BIGINT]		FK, NOT NULL
				club_id 							[BIGINT]		FK, NOT NULL
				registered_at						[TIMESTAMP] 	NOT NULL
				status								[VARCHAR(20)] 	NOT NULL

				UNIQUE(championship_season_id, club_id)	
				UNIQUE(id, championship_season_id)

			coach
				id 									[BIGINT]		PK
				name 								[VARCHAR(150)]	NOT NULL
				country_id							[BIGINT]		FK, NOT NULL
				birth_date							[DATE]	

			club_coach
				id 									[BIGINT]		PK
				club_id 							[BIGINT]		FK, NOT NULL
				coach_id 							[BIGINT]		FK, NOT NULL
				start_date							[DATE]			NOT NULL
				end_date							[DATE]

				CHECK(end_date IS NULL OR end_date >= start_date)	

			player
				id 									[BIGINT]		PK
				name 								[VARCHAR(150)]	NOT NULL
				country_id 							[BIGINT]		FK, NOT NULL
				birth_date 							[DATE]			NOT NULL
				preferred_foot						[CHAR(1)]		NOT NULL

				CHECK(preferred_foot IN('L', 'R', 'B'))

			squad_membership
				id 									[BIGINT]		PK
				championship_season_id 				[BIGINT]		NOT NULL
				championship_season_club_id			[BIGINT]		NOT NULL
				player_id							[BIGINT]		FK, NOT NULL
				start_date							[DATE]			NOT NULL
				end_date							[DATE]

				FOREIGN KEY (
					championship_season_club_id,
					championship_season_id
				)
				REFERENCES championship_season_club (
					id,
					championship_season_id
				)

				UNIQUE(championship_season_club_id, player_id)
				UNIQUE(id, championship_season_club_id)

				CHECK(end_date IS NULL OR end_date >= start_date)

				EXCLUDE USING gist (
					championship_season_id WITH =,
					player_id WITH =,
					daterange(
						start_date,
						COALESCE(end_date, 'infinity'::date),
						'[]'
					) WITH &&
				)

			squad_membership_assignment
				id 									[BIGINT]		PK
				squad_membership_id					[BIGINT]		NOT NULL
				championship_season_club_id 		[BIGINT]		NOT NULL
				shirt_number						[SMALLINT]		NOT NULL
				position							[VARCHAR(30)]	NOT NULL
				start_date							[DATE]			NOT NULL
				end_date							[DATE]

				FOREIGN KEY (
					squad_membership_id,
					championship_season_club_id
				)
				REFERENCES squad_membership (
					id,
					championship_season_club_id
				)

				CHECK(shirt_number BETWEEN 1 AND 99)
				CHECK(end_date IS NULL OR end_date >= start_date)

				EXCLUDE USING gist (
					squad_membership_id WITH =,
					daterange(
						start_date,
						COALESCE(end_date, 'infinity'::date),
						'[]'
					) WITH &&
				)

				EXCLUDE USING gist (
					championship_season_club_id WITH =,
					shit_number WITH =,
					daterange(
						start_date,
						COALESCE(end_date, 'infinity'::date),
						'[]'
					) WITH &&
				)

			game
				id 									[BIGINT] 		PK
				championship_season_id 				[BIGINT] 		FK, NOT NULL
				scheduled_at 						[TIMESTAMP]		NOT NULL
				home_championship_season_club_id	[BIGINT]		NOT NULL
				away_championship_season_club_id 	[BIGINT]		NOT NULL
				stadium_id 							[BIGINT]		FK, NOT NULL
				status								[VARCHAR(20)]	NOT NULL
				home_score							[SMALLINT]
				away_score							[SMALLINT]

				FOREIGN KEY (
			        home_championship_season_club_id,
			        championship_season_id
			    )
			    REFERENCES championship_season_club (
			        id,
			        championship_season_id
			    )

			    FOREIGN KEY (
			        away_championship_season_club_id,
			        championship_season_id
			    )
			    REFERENCES championship_season_club (
			        id,
			        championship_season_id
			    )

				CHECK(home_championship_season_club_id <> away_championship_season_club_id)
				CHECK(
					(home_score IS NULL OR home_score >= 0)
					AND
					(away_score IS NULL OR away_score >= 0)
				)

			country
				id 									[BIGINT]		PK
				name 								[VARCHAR(100)]	NOT NULL, UNIQUE
				iso_code							[CHAR(2)]		NOT NULL, UNIQUE

			stadium
				id 									[BIGINT] 		PK
				name 								[VARCHAR(150)]	NOT NULL
				city								[VARCHAR(100)]	NOT NULL
				state 								[VARCHAR(100)]
				country_id							[BIGINT]		FK, NOT NULL
				capacity							[INTEGER]		

				UNIQUE(name, city, country_id)
				CHECK(capacity IS NULL OR capacity > 0)
